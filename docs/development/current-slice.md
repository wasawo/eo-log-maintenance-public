# Current Slice — S2 PC-A Archive 合成データE2E（削除なし）

このファイルは現在のスライスの作業範囲の正本。利用者の指示でS1からS2へ切り替える。正式な要件・ACの定義を変更しない。

## ゴール
合成データ・隔離領域・模擬Driveを用い、`scripts/ArchiveLogs.ps1` をPC-A役割で起動し、「現在の模擬cloud列挙 → 期間判定 → 平坦化 → PC-Aの模擬archiveへコピー → SHA-256照合 → 結果表示」を一貫して実行する。元は全て保持する。

## 承認済みの選択・役割
- BattleLogは前年12月31日以前、ErrorReportは前々年12月31日以前の全適格分をファイル名の日付から選ぶ。LastWriteTimeで代用しない。
- PC-Aだけがarchiveを実行できる。PC-Bの完了や期間記録を待たず現在cloudの適格分を処理し、遅着分は次の実行で扱う。
- 保存先はログ種別ごとの共通フォルダ直下。同名同内容は再利用、異内容は元を残して競合保留し、自動改名・上書きしない。

## 検証対象
正式な定義は[実装計画§2](implementation-workflow.md#2-一連の受け入れ条件)に従う。AC-02/03/04/05/09/11のうち合成環境の列挙・選択・コピー・平坦化・再利用・競合・役割拒否を部分検証する。AC-06のコピー/照合失敗時の元保全も確認する。元削除・結果不明からの回復・実Drive等の未検証条件と区別し、正式AC合格とはしない。

## 範囲外
元ファイル/クラウド元の削除、実ログ/本番Driveアクセス、実Drive adapter、定期実行、実設定の使用、配布/本番適用、新しい削除/安全/権限仕様、S3への移行。

## スライス完了条件
- 正式Archive入口を実行し、両ログ種別を現在の模擬DriveからPC-Aの模擬archiveへコピー・照合できる。S1の入口E2Eも維持する。
- 年末/年始の期間境界、対象外、不正名、不正日付、対象0件、列挙失敗を確認し、正常な対象なしと失敗を区別する。
- サブフォルダの平坦化と元の個別識別、同名同内容の再利用、異内容の非上書き/保留、コピー/照合失敗時の元保持を確認する。
- PC-Bのarchiveを拒否し、PC-B未実行でも既存分を処理でき、遅着分を次回扱える。
- 結果の処理件数・コピー検証成功・対象外・失敗・保留と終了コードを示す。移動完了件数は0で、合成専用の両入口を配布可能としない。
- 実行コマンド・結果・正式ACの部分検証と未検証をhandoffへ記録する。承認済みの安全条件は維持する。

## 作業上限と停止
今回のS2範囲はPR作成と標準条件成立時のsquashマージまで事前許可済み。PR3件または20分、S2完了、承認が必要な判断事項の発生のいずれかで停止する。S3は未承認で、着手しない。
